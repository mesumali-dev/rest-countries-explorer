> An interactive global geography and demographic intelligence explorer powered by Python, Streamlit, and the REST Countries API.

---

## Features

- **Country Search & Lookup:** Search any sovereign nation by name, capital, or currency code.
- **Demographic Telemetry:** Capital cities, population metrics, geographic coordinates, and regional classifications.
- **National Flags & Currencies:** High-definition SVG flag rendering alongside official currencies and language rosters.
- **Regional Filtering:** Filter nations across Asia, Europe, Africa, Americas, and Oceania.

---

## Run Locally

```bash
git clone https://github.com/mesumali-dev/rest-countries-explorer.git
cd rest-countries-explorer

pip install -r Requiremnt.txt
streamlit run app.py
```
